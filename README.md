# CD Ripper

Reads an audio CD, looks it up on MusicBrainz, lets you edit the details, and rips tracks to
WAV, MP3, FLAC or OGG with tags and cover art embedded (WAV carries no tags).
Double-click the cover to view it full size.

Build: upload this folder to GitHub; the Actions tab builds CdRipper.exe (see .github/workflows/build.yml).
